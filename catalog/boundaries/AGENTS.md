# AGENTS.md — Boundaries and Districts

6 collections. Every GeoParquet here is in **EPSG:3566** (NAD83/HARN Utah Central, US survey feet), so lengths and areas come out in feet. Each collection's own `AGENTS.md` carries its schema, its coded-value lists and a query that runs.

- [Sandy City Boundary](./city-boundary/) — see its README for columns and caveats

- [Salt Lake County City Borders](./slco-city-borders/) — see its README for columns and caveats
- [Voting Precincts](./voting-precincts/) — see its README for columns and caveats
