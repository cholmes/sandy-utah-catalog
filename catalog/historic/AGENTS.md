# AGENTS.md — Historic Sandy

3 collections. Every GeoParquet here is in **EPSG:3566** (NAD83(HARN) / Utah Central, US survey feet), so lengths and areas come out in feet. Each collection's own `AGENTS.md` carries its schema, its coded-value lists and a query that runs.

- [Contributing Historic Structures (2026 Study)](./contributing-structures/) — see its README for columns and caveats
- [Historic Photographs](./historic-photos/) — see its README for columns and caveats
- [Historic Sandy Walking Tour](./historic-walking-tour/) — see its README for columns and caveats

Sandy City publishes no licence for this data. See the [catalog agent guide](../AGENTS.md).
